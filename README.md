# TechStore - Semana 7

Proyecto eCommerce desarrollado con React y Vite.

## Funcionalidades

- Listado con nombre, precio normal, precio oferta, descripción e imagen.
- Búsqueda con `onChange`.
- Carrito con `useState`.
- Agregar con `onClick`.
- Eliminar productos.
- Contador y total.
- Renderizado condicional.
- Componentes funcionales reutilizables.
- Bootstrap 5 responsive.

## Ejecutar

```bash
npm install
npm run dev
```

## Publicar

```bash
npm run deploy
```

La configuración de Vite usa la ruta base del repositorio `TechStore-Fronted-semana6`.
